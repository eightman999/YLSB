## 6モデルの読み方

calibration report は入力された6モデルの task rows と performance rows から計算する。Essential accuracy は rerun/invalid を capability 分母へ入れず、空応答は health に残す。Sentinel は semantic correct と strict format を別表示し、Fastest Useful は gate pass かつ比較可能な実測 mean がある候補だけから選ぶ。

具体値は生成物 [`results/v0.4-rc1/derived/v0.4-rc1-calibration.md`](../results/v0.4-rc1/derived/v0.4-rc1-calibration.md) の表を正とする。GPT-OSS H03 は入力 row の実測から semantic 4/4、strict 3/4 と記録される。空応答16件、rerun 15件、invalid overlap 1件も同じ表に保存される。

生成時点の6モデル比較は次の通りである。TG は入力 performance の original_run / R0 / TG128 の repeat mean、正式 slot 未検証の候補値である。

| model | v0.3 Smallest | v0.4 Smallest | v0.3 Fastest | v0.4 Fastest | Essential | Sentinel semantic/strict | empty/rerun | mean TG128 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| gemma-4-e4b-it | pass | pass | fail | pass | 14/20 (70%) | 0/4, 3/4 | 0/0 | 52.0207 |
| glm-4.7-flash | pass | pass | fail | pass | 14/20 (70%) | 0/4, 3/4 | 0/0 | 54.384 |
| gpt-oss-20b | fail | fail | fail | fail | 18/18 (100%) | 4/4, 3/4 | 16/15 | 76.7333 |
| nemotron-3.5-lightning-30b-a3b | fail | fail | fail | fail | 10/20 (50%) | 0/4, 3/4 | 0/0 | 80.7377 |
| qwen3-0.6b | fail | fail | fail | fail | 12/20 (60%) | 0/4, 1/4 | 0/0 | 214.144 |
| qwen3-4b | fail | fail | fail | fail | 15/20 (75%) | 0/4, 3/4 | 0/0 | 70.031 |

この比較で gate を通過する実測最速候補は glm-4.7-flash (54.384 tok/s) であり、qwen3-0.6b の速度だけを理由に正式 slotへ昇格させていない。

## 制限

これは rc1 の再解釈で、hardware family、multi-GPU topology、runtime、seed/template/VRAMを横断した新規測定ではない。sensitivity は閾値候補の比較であり、恒久 threshold や正式 performance slot を確定しない。baseline HEADからの tag/release/push は実施していない。
